## Additions

- Added optional smooth turning with the right stick and an adjustable speed of 30-180 degrees per second

## Changes

- Kept 22.5-degree snap turning as the default; the right stick still moves the cursor in puzzle mode
- Updated controls and settings documentation

## Bugfixes

- Fixed puzzle activation, clicking, and drawing using the wrong trigger when controller connection order changes
- Removed the game's angle stepping during smooth turns and improved turn timing

Extract the full ZIP and run WitnessVR.exe. Close the game and launcher before updating.

Known limitations: smooth turning remains experimental; the latest timing changes still need headset validation. Excessive forward movement when entering some puzzles remains unresolved.
