## Additions

- Added optional controller-tracked glove hands, with palm-based alignment and grip-button open/close animation.
- Added an Automatic puzzle positioning setting to suppress panel approaches on subsequent puzzle entries and linked-panel changes.

## Changes

- Hands are off by default; enable Show hands in Settings and save to apply.
- Hidden the unsuccessful world-occlusion experiment and disabled saved preview preferences. Hands can still appear over walls and puzzle panels.
- Simplified release downloads to the portable ZIP without separate checksum files.

## Bugfixes

- Fixed leftover launcher content and footer rendering when changing tabs.
- Preserved stick cursor control when controller pointing loses a valid pose.
- Rearmed trigger input after stale polls to prevent an old held press from carrying into resumed input.

Extract the full ZIP and run WitnessVR.exe. Close the game and launcher before updating; replace the full package because the loader and runtime protocols changed.

Known limitations: VR bindings are tested with Knuckles controllers. SteamVR's default Index binding maps both a firm grip squeeze and A to grip, so either may close a glove. Hands provide visuals only, with no individual finger tracking or physical interaction. World occlusion is unavailable. Some perspective puzzles require native positioning; re-enable Automatic puzzle positioning and re-enter if viewing or interaction becomes difficult. Smooth turning and wider headset/controller compatibility need further testing.
