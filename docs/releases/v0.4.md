## Additions

- Added a Controls tab with VR button mappings and keyboard shortcuts

## Changes

- Simplified controller selection to VR or Gamepad (Gamepad is disabled for now)
- Cleaned up obsolete development builds and preview packages

## Bugfixes

- Fixed the launcher showing a remote-thread error when closing the game
- Cleared session status and pending attachment when the game exits

Extract the full ZIP and run WitnessVR.exe. Close the game and launcher before updating.

Known limitations: VR bindings are tested with Knuckles controllers. Smooth turning remains experimental, and excessive forward movement when entering some puzzles remains unresolved.
